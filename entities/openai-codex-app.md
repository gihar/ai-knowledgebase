# OpenAI Codex App

OpenAI Codex App — настольное приложение OpenAI для работы с агентом Codex, согласно пересланному анонсу о поддержке этого приложения в Ollama 0.24. Источник — рассылка/клиппинг, а не официальная страница продукта, поэтому уверенность `low` до проверки по документации OpenAI.

## Возможности, упомянутые в источнике

Источник описывает Codex App как настольную версию для параллельной работы над несколькими потоками Codex и приписывает ему:

- параллельную работу над несколькими потоками Codex;
- встроенную поддержку дерева задач (task tree);
- интеграцию с Git;
- встроенный браузер: Codex может загружать локальные серверы и сайты, а пользователь — добавлять аннотации прямо на страницу для запроса изменений;
- режим обзора (review mode): просмотр кода, комментарии и правки не покидая приложения.

## Связь с Ollama

Согласно [[ollama]] 0.24, приложение можно запустить поверх локальных моделей Ollama командой `ollama launch codex-app`, выбрав модель для агентных и кодовых задач. Это позиционирует Codex App как агентный фронтенд, который может работать как с бэкендом OpenAI, так и с локальными моделями.

## Отношение к Codex SDK

Codex App — это десктопный продукт, тогда как [[openai-codex-python-sdk]] (по другому пересланному источнику) — программный способ встраивания тех же сессий Codex в Python-приложения. Оба относятся к [[agentic-coding-workflows]]: первый как готовый UI, второй как библиотека для оркестрации.
