# cyber — скиллы безопасности для AI-агентов

[Репозиторий serejaris/cyber](https://github.com/serejaris/cyber/tree/main/skills) — набор из девяти `SKILL.md` для AI-кодинг-агентов (Claude Code, Cursor, Codex и совместимых инструментов). Это инструкции по проверке безопасности, а не самостоятельный сканер. Снимок [README по коммиту `76e214a`](../raw/articles/cyber-security-skills-readme-2026-11-04.md) сохранён в базе; состав каталога проверен по GitHub на 04.11.2026.

## Что входит

- `host-pentest` — аудит своей машины или разрешённого хоста: сетевые сервисы, доступы, конфигурация.
- `compromise-check` — поиск признаков компрометации и подозрительной активности.
- `web-pentest` — проверка своего или явно разрешённого веб-сервиса.
- `passive-recon` — пассивная разведка по открытым данным без активного тестирования цели.
- `php2shell-emergency` — экстренная проверка PHP-инфраструктуры под конкретные заявленные уязвимости; применимость CVE и исправлений нужно сверять отдельно с первичными бюллетенями.
- `secret-audit` — проверка секретов в репозитории, в том числе в истории Git.
- `host-privacy-sweep` — поиск чувствительных данных и токенов на машине.
- `stack-researcher` — изучение стека и применимости известных уязвимостей.
- `internal-lab-validation` — воспроизведение находок на собственном изолированном стенде.

## Границы применения

README требует проверять только собственные системы или системы с письменным разрешением; активные проверки — на своём стенде либо после явного одобрения. Отчёт агента требует повторной проверки человеком. Лицензия репозитория — MIT. Скиллы не устанавливались и не запускались: пригодность команд, безопасность работы на конкретном хосте и результаты аудита здесь не подтверждены. Перед установкой следует прочитать соответствующий `SKILL.md` и проверить команды и сетевые обращения — см. [[agent-skills]].

Коллекция относится к практикам [[agentic-coding-workflows]]: агент исполняет предписанную процедуру и собирает доказательства, но решение о дальнейших действиях остаётся за человеком.
