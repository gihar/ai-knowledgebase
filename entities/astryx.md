# Astryx

[Astryx](https://github.com/meta/astryx) — открытая дизайн-система Meta для React-интерфейсов, выросшая из внутреннего инструментария компании. В [README по фиксированному коммиту](../raw/articles/astryx-readme-2026-11-10.md) Meta заявляет о восьми годах внутреннего развития, применении в более чем 13 000 приложений и **150+ доступных UI-компонентах**. Проект находится в **бета-статусе** на дату среза 10.11.2026; лицензия MIT.

## Возможности

- Типизированные компоненты для **React 19+**, готовые CSS-стили, адаптируемые темы и тёмный режим; в README перечислены семь готовых тем и шаблоны страниц.
- Внутри проекта стили создаются через StyleX, но для потребителя не требуется отдельный build-плагин; переопределения допускаются через CSS, CSS modules или Tailwind.
- Настройка темы через CSS custom properties, композиция компонентов и `swizzle` для переноса исходного кода отдельного компонента в свой проект.
- CLI предоставляет документацию, шаблоны и команды для работы с компонентами. Одинаковые соглашения API, документация и CLI задуманы для разработчиков и coding-агентов; это **не** агентный runtime и не протокол agent/UI.
- В [приложенном видео](../raw/assets/astryx-demo-2026-11-10.mp4) показаны сайт, каталог компонентов, переключение темы, примеры вроде date picker/hover card, руководство Getting Started и GitHub-репозиторий. Видео не заменяет проверку работы набора в собственном проекте.

## Ограничения и расхождения

[Пересланный пост](../raw/articles/astryx-forwarded-2026-11-10.md) называет **170+ компонентов**, но проверенный README официального репозитория на 10.11.2026 указывает **150+**. Здесь сохранены обе формулировки с происхождением; точное число компонентов по каталогу отдельно не пересчитывалось. Тезис «сразу в прод» не означает подтверждённую зрелость для любого проекта: официальный README помечает систему как beta. Чарты/обёртка Vega доступны только в canary, а `lab` не опубликован в npm (по README).

Для [[ai-engineering|AI-инжиниринга]] и [[agentic-frontend-stack|агентного фронтенда]] Astryx может служить слоем повторно используемых UI-компонентов и правил для coding-агента, но не подменяет интеграцию с агентным backend, состояние или подтверждение действий. Практическое внедрение, качество визуального результата и совместимость с конкретным стеком здесь не тестировались.
