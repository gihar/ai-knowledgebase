# awesome-free-llm-apis

`awesome-free-llm-apis` — GitHub-репозиторий `amardeeplakshkar/awesome-free-llm-apis`, который позиционируется как curated list «permanently free LLM APIs» с лимитами, OpenAI SDK compatibility, SDK, speed tiers и списками бесплатных моделей. ^[raw/articles/awesome-free-llm-apis-directory-2026-07-06.md]

## Ключевые факты

- Репозиторий: [amardeeplakshkar/awesome-free-llm-apis](https://github.com/amardeeplakshkar/awesome-free-llm-apis).
- Лицензия по GitHub API на момент ingest: CC0-1.0.
- Обновление по GitHub API: `updated_at=2026-07-06T02:53:27Z`, `pushed_at=2026-07-04T15:17:04Z`.
- Заявленная ценность: собрать в одном месте free-tier LLM API без trial credits, временных промо и кредитной карты.
- Поля сравнения в README: free models, rate limits, OpenAI compatibility, SDKs, speed tier.

## Провайдеры и применимость

В README и пересланном посте упоминаются Google AI Studio / Gemini, Groq, Cerebras, OpenRouter, NVIDIA NIM, Mistral, GitHub Models, Hugging Face, Cloudflare Workers AI, Cohere и другие провайдеры. Для [[free-llm-api-directories]] это полезный справочник, если нужно быстро подобрать endpoint для Cursor, Claude Code или другого [[agentic-coding-workflows]] инструмента с OpenAI-compatible API.

## Caveats

- Данные о лимитах API быстро устаревают; перед использованием нужно проверять документацию конкретного провайдера и дату последней проверки в README.
- Утверждение пересланного поста про «25 тыс. звёзд» не подтвердилось: GitHub API для найденного репозитория на момент ingest показал 66 stars. Возможны накрученный/ошибочный соцсетевой сниппет, другой репозиторий или рассинхрон поискового индекса. Поэтому страница помечена `contested: true`.
- «Бесплатно навсегда» следует трактовать как текущую заявленную/наблюдаемую free-tier модель, а не юридическую гарантию.
