# Screenshot to Code

[Репозиторий на GitHub](https://github.com/abi/screenshot-to-code) — open-source-инструмент, который превращает скриншоты, макеты из Figma и записи экрана в рабочий frontend-код с помощью AI. На момент фиксации материала у репозитория более 74 тысяч звёзд.

## Что умеет

- генерировать интерфейсы из скриншотов и mockup;
- поддерживать HTML + Tailwind, HTML + CSS, React + Tailwind, Vue + Tailwind, Bootstrap и Ionic + Tailwind;
- извлекать и переиспользовать реальные изображения и логотипы из исходного скриншота;
- работать с записью экрана сайта и собирать на её основе функциональный прототип;
- выполнять необязательный screenshot preview: агент рендерит результат в Chromium и визуально проверяет его.

## Архитектура и запуск

Проект состоит из React/Vite frontend и FastAPI backend. Для локального запуска нужны ключи хотя бы одного провайдера моделей — OpenAI, Anthropic или Gemini. Gemini рекомендуется для извлечения assets, а Replicate — для генерации и редактирования изображений. Есть Docker-сценарий и hosted-вариант на [screenshottocode.com](https://screenshottocode.com).

Лицензия репозитория — **MIT**. README указывает, что для локального preview нужен Chromium; backend запускается через Uvicorn, frontend — через `pnpm dev`.

## Пример промпта для Codex или Claude Code

```text
Используя этот репозиторий, реализуй приложенный скриншот как полностью рабочий экран фронтенда.

Воспроизведи расположение элементов, пропорции, отступы, шрифты, цвета и позиции изображений по скриншоту, но не добавляй ничего от себя.

После реализации сделай скриншот результата, сравни его с оригиналом и последовательно исправь все заметные различия.

Раздели компоненты и стили по их ролям, а повторяющиеся элементы интерфейса вынеси в переиспользуемую структуру.

После завершения кратко объясни, как запустить проект и какие отличия от оригинала ещё остались.
```

Для первого варианта достаточно передать скриншот вместе с этим промптом. Если передать запись экрана со сценарием использования, инструмент может восстановить не только внешний вид, но и часть взаимодействий и анимаций.

## Практический смысл

Screenshot to Code — пример [[ai-engineering]]-инструмента на стыке [[agentic-frontend-stack]] и [[agentic-coding-workflows]]: скриншот становится входным артефактом, а результатом — проверяемый frontend-код, который можно дорабатывать, запускать и хранить в Git. Это полезнее простого экспорта картинки, но качество результата зависит от модели, доступности исходных assets и обязательной визуальной проверки.

## Caveats

- README проекта меняется вместе с поддерживаемыми моделями и способами запуска; перед установкой нужно сверять актуальные команды.
- Для полноценной локальной работы потребуются API-ключи и зависимости frontend/backend.
- Автоматически сгенерированный интерфейс следует проверять вручную: визуальное сходство не гарантирует корректную семантику, доступность или production-качество кода.
