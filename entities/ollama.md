# Ollama

Ollama — инструмент для локального запуска языковых моделей. В пересланном анонсе фигурирует релиз Ollama 0.24, добавляющий поддержку настольного приложения [[openai-codex-app]]. Источник — рассылка/клиппинг, версия и детали не проверены по официальному changelog, поэтому уверенность `low`.

## Релиз 0.24 (по источнику)

Источник утверждает, что Ollama 0.24:

- добавляет поддержку [[openai-codex-app]] — настольной версии OpenAI для параллельной работы над потоками Codex с деревом задач и интеграцией Git;
- запускается командой `ollama launch codex-app`;
- поддерживает восстановление профиля Codex по умолчанию через `ollama launch codex-app --restore`.

## Модели для агентных и кодовых задач (по источнику)

Источник рекомендует под Codex App следующие модели (имена приведены как в источнике и не верифицированы):

- `kimi-k2.6:cloud` (с поддержкой машинного зрения) и `glm-5.1:cloud` — для облачной подписки Ollama;
- `nemotron-3-super:cloud`, `gemma4:31b:cloud`, `qwen3.6` — как модели с надежным вызовом инструментов при отсутствии платной облачной подписки.

> Caveat: перечисленные версии моделей выходят за пределы проверяемых знаний и приведены исключительно как цитата из источника от 2026-06-03.

## Почему это важно

Ollama как локальный рантайм в связке с агентным фронтендом смыкает [[agentic-coding-workflows]] с локальным/edge-инференсом: агент для разработки может работать поверх локальных моделей без обязательной зависимости от облачного бэкенда.
