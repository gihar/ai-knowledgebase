# cyber — security skills для AI-агентов

Набор скиллов, которые подключаются к вашему кодинг-агенту (Claude Code, Cursor, Codex и другим) и учат его проверять безопасность: свой сервер, свой сайт, свои ключи — и показывать, куда пришли атаковать.

Каждый скилл — это папка с инструкцией для агента: что проверять, какими командами, что писать в отчёт. Никакой магии: только системные команды, журналы и понятный порядок действий.

## Правила (важнее скиллов)

1. **Проверяйте только своё.** Свой сервер, свой сайт, свой код — можно. Чужое — только с письменного разрешения владельца; проверка чужого без разрешения считается взломом.
2. **Только чтение по умолчанию.** Активные проверки (POST, эксплойты, сканирование портов) — на своём стенде или после явного одобрения.
3. **Агент находит — человек решает.** Отчёт агента это список находок с доказательствами, а не приговор. Каждую находку проверяют второй раз перед действиями.

## Скиллы

| Папка | Что делает | Когда запускать |
|---|---|---|
| `host-pentest` | **Аудит своего сервера**: что торчит наружу, кто имеет вход, где слабые места | Раз в квартал и после любых изменений |
| `compromise-check` | **«Вас взломали?»** — проверка по следам: чужие входы, ключи, файлы, попытки уйти наружу | При любом подозрении, до паники |
| `web-pentest` | **Пентест сайта по разрешению**: находки с доказательством запрос-ответ | На свой сайт или с ROE от клиента |
| `passive-recon` | **Разведка периметра без касания**: что о вас видно из открытых источников | До договора и перед проверкой |
| `php2shell-emergency` | **Вышла страшная CVE** — срочная проверка своих PHP-машин: версия, следы, митигации | В день выхода критичной дыры |
| `secret-audit` | **Утёкшие ключи в репозитории**: история git, файлы, артефакты | Перед публикацией репо и регулярно |
| `host-privacy-sweep` | **Приватные данные на машине**: сессии, токены, истории команд | Перед передачей машины или раз в квартал |
| `stack-researcher` | **Досье стека**: что стоит, каких версий, какие дыры касаются | После каждого изменения стека |
| `internal-lab-validation` | **Проверка находки на своём стенде**: воспроизвести уязвимость на копии, не на проде | Когда находку нужно доказать |

## Установка

Скопируйте нужную папку в каталог скиллов вашего агента:

```bash
git clone https://github.com/serejaris/cyber.git
cp -R cyber/skills/host-pentest ~/.claude/skills/
```

Для Claude Code скилл подхватится автоматически из `~/.claude/skills/` или из `.claude/skills/` внутри проекта. Для других агентов — по их документации: скилл это просто `SKILL.md` с инструкциями.

## С чего начать

Новичку: `host-pentest` на своём сервере, потом `secret-audit` на своём репо. Это два действия, которые закрывают больше всего при нуле риска — оба только читают и ничего не меняют.
