# OpenAI Apps SDK UI — пересланное сообщение

Хотите создавать плагины для ChatGPT? Теперь даже не нужно разрабатывать интерфейс с нуля.

OpenAI ранее опубликовала (https://github.com/openai/apps-sdk-ui) исходный код Apps SDK UI.

Библиотека содержит готовые компоненты: кнопки, элементы чата, всплывающие подсказки, цветовые схемы и адаптивные макеты.

Она построена на React и Tailwind и специально предназначена для создания интерактивных интерфейсов внутри ChatGPT.
