# Screenshot to Code — пересланное описание и промпт

[Видеодемонстрация Screenshot to Code](../assets/screenshot-to-code-demo-2026-08-27.mp4)

Опенсорсный инструмент, который превращает интерфейс со скриншота в код.

На GitHub у проекта уже больше 74 тысяч звёзд.

ИИ анализирует референсный скриншот и автоматически восстанавливает в коде расположение элементов, отступы, кнопки и другие детали интерфейса.

Если при вайбкодинге референс и результат постоянно расходятся, можно использовать этот инструмент для быстрого первого варианта, а потом уже подгонять его под свой проект.

Если показать сценарий использования через запись экрана, он умеет воспроизводить даже взаимодействия и анимации.

В Codex или Claude Code достаточно передать скриншот вместе с промптом.

## Пример промпта

```text
Используя этот репозиторий, реализуй приложенный скриншот как полностью рабочий экран фронтенда.

Воспроизведи расположение элементов, пропорции, отступы, шрифты, цвета и позиции изображений по скриншоту, но не добавляй ничего от себя.

После реализации сделай скриншот результата, сравни его с оригиналом и последовательно исправь все заметные различия.

Раздели компоненты и стили по их ролям, а повторяющиеся элементы интерфейса вынеси в переиспользуемую структуру.

После завершения кратко объясни, как запустить проект и какие отличия от оригинала ещё остались.
```
