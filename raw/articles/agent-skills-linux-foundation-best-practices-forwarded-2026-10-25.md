# Agent Skills передан фонду и рекомендации по созданию скиллов — пересланное сообщение

Anthropic передала стандарт Agent Skills в Linux Foundation, тот же фонд, которому ранее был передан MCP.

С момента запуска стандарта в октябре прошлого года было опубликовано 1 миллион скиллов, которые установили почти 280 миллионов раз. Сегодня Agent Skills поддерживают более 70 платформ для ИИ-агентов, включая ChatGPT, Cursor, GitHub Copilot и VS Code.

За прошедший год сформировался единый подход к созданию скиллов. Официальное руководство по их разработке также передали фонду.

Шесть самых полезных правил из этого руководства:

1. Сначала выполните задачу вместе с агентом. Только после этого превращайте в скилл успешно сработавшие шаги, внесённые вами исправления, форматы входных и выходных данных, а также дополнительный контекст. Если модель пишет скилл, опираясь лишь на общие знания, результат будет наполнен бесполезными рекомендациями вроде «обрабатывайте ошибки надлежащим образом».

2. Проверяйте каждую строку. Спросите себя, ошибся бы агент без этой инструкции. Если нет, удалите её.

3. Уделяйте особое внимание описанию скилла. При запуске агент читает только название и описание, поэтому именно описание определяет, будет ли скилл вообще использован. Формулируйте его в виде «Используй этот скилл, когда...», делайте достаточно настойчивым, перечисляйте ситуации, которые пользователи могут не указывать напрямую, и укладывайтесь в 1024 символа.

4. Не перегружайте `SKILL.md`. Ограничьте его объём 500 строками и 5000 токенами. Подробности выносите в каталог `references/`, указывая, когда агенту следует читать каждый файл.

5. Разделяйте строгие инструкции и рекомендации. Для действий, в которых особенно легко допустить ошибку, указывайте точные команды. Там, где требуется самостоятельное решение, объясняйте причины выбора. Если задачу можно выполнить несколькими способами, предлагайте один вариант по умолчанию.

6. Составляйте список типичных ошибок (gotchas). Во многих скиллах именно он оказывается самой полезной частью. Каждый раз, когда вам приходится исправлять ошибку агента, добавляйте соответствующее замечание в список.

Сразу после того, как агент завершит задачу, которую вы часто ему поручаете, отправьте следующий промпт в Claude Code в рамках той же сессии, чтобы сохранить успешный подход в виде стандартного скилла.

Промпт для Claude Code:

Следуя руководству https://agentskills.io/skill-creation/best-practices, преврати задачу, которую мы только что выполнили, в скилл.

Используй исключительно те шаги, которые успешно сработали в этой сессии, мои исправления, а также связанные с ними решения из файлов `CLAUDE.md`, `AGENTS.md` и истории Git. Не восполняй пробелы общими знаниями.

Сформулируй описание в формате «Используй этот скилл, когда...». Включи ситуации, которые я не упоминал напрямую, но в которых скилл должен активироваться. Длина описания не должна превышать 1024 символа.

Ограничь размер `SKILL.md` 500 строками. Подробную информацию вынеси в каталог `references/`, указав, в каких случаях агенту следует обращаться к каждому файлу.

Выдели отдельный раздел с типичными ошибками и подводными камнями.

Для названия скилла используй только строчные латинские буквы, цифры и дефисы. Название должно совпадать с именем каталога.

В завершение создай 2–3 реальных тестовых сценария в файле `evals/evals.json`, указав для каждого промпт и ожидаемый результат. Запусти все тесты и покажи их результаты, а также опиши выполненные действия.
