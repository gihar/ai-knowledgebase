# ai-knowledgebase

База знаний про AI: искусственный интеллект, машинное обучение, большие языковые модели, автономных агентов, AI-инжиниринг, оценку, безопасность/alignment, inference, обучение, tooling, продукты, компании, лаборатории и практические паттерны внедрения.

## Структура

- `SCHEMA.md` — основные wiki-соглашения, схема страниц и таксономия тегов.
- `AGENTS.md` — инструкции для AI-агентов по работе с базой знаний.
- `index.md` — главный каталог wiki-страниц.
- `log.md` — append-only лог всех действий в базе.
- `raw/` — неизменяемые исходные материалы (статьи, документы) и ассеты.
- `entities/` — страницы конкретных сущностей: моделей, компаний, инструментов, фреймворков.
- `concepts/` — описание AI-концептов, теорий и практик.
- `comparisons/` — сравнительный анализ различных подходов или продуктов.
- `queries/` — синтезированные ответы на сложные исследовательские вопросы.

## Основные принципы

- **Синтез на основе источников**: предпочтение краткому синтезу из `raw/` вместо общих объяснений.
- **Связанность**: активное использование `[[wikilinks]]` для построения графа знаний.
- **Прослеживаемость**: использование маркеров происхождения источников на страницах синтеза.
- **Строгий формат**: обязательный YAML frontmatter на каждой странице.
